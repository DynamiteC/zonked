# Nature sample licences

Every loop shipped under `web/public/samples/` is listed here. Only CC0 or public domain material is used.
`node scripts/check-samples.mjs` fails when a shipped file is missing from this table, has a licence outside
the allow list, or has a different SHA-256.

Allow list: `CC0 1.0`, `Public domain (PD-author, dedicated by the author)`.
Public domain here means the recording author dedicated it to the public domain, as stated on the Commons file page.

## How the loops were made

1. Download the source file from its source page. No login was needed. yt-dlp was not used.
2. Cut the segment shown above, plus a 4 to 5 s tail, convert to mono 32 kHz.
3. Loop point: equal-power crossfade of the tail into the head, so the end flows into the start.
4. Gain: normalised to about -23 LUFS, then lowered if needed so the peak stays under -6.5 dBFS.
   The stream and breeze loops are peaky and end quieter (about -33 LUFS) to hold that peak limit.
5. Encode MP3, 56 kbps, mono (libmp3lame). MP3 decodes in Chrome, Firefox and Safari.
6. The file carries a .json extension so the Kiro Crew gateway can serve it. The app fetches it as an
   arrayBuffer, the same way as `dsp_core.wasm.json`. The browser PWA uses the same files.

## Not used

- Epidemic Sound: considered and rejected. It is a paid subscription library. Its licence does not allow
  bundling or redistributing tracks inside a public repository or app.
- Wikimedia Commons files under CC BY-SA, CC BY or CC BY-NC (several rain, forest and stream recordings):
  the share-alike and attribution terms do not fit this repository.
- A flute or village-flute loop: the only public domain flute files found are 13 s phrases, shorter than the
  20 s loop minimum, and a played phrase does not loop well. No clean loop was found, so none is shipped.
- A wind-only loop: the only CC0 wind file is a harsh howl at 16 kHz, not soft wind. The breeze loop
  (gentle breeze with birds) covers soft wind.
- A waterfall loop: none found under an allowed licence. River rapids is shipped instead.
- yt-dlp was not needed: every shipped file came from Wikimedia Commons.

recording and need no licence row. The check script reads web/src/audio/samples/catalog.ts and requires every
entry with kind 'synth' to be listed here, and every row here to exist in the catalog.

## Round 3 (2026-11-27 UTC): 15 more loops

All 15 new loops came from Wikimedia Commons. For each one the file page was read and the licence template checked:
`cc-zero` or `self` with CC0 for CC0 files, `PD-author` (PDSounds, author dedication) or `PD-self` (the author's own
dedication) for public domain files. No login was used. yt-dlp was not used. Nobody has listened to these loops.

Process, same as round 1 with two changes:

1. Segment of 20 to 35 s plus a 4.5 s lead-in. The lead-in is blended into the tail with an equal-power crossfade.
2. Gain targets about -26 LUFS. A transparent limiter (3 ms attack, 80 ms release) holds the peak at or under -7.4 dBFS
   after MP3 encoding. It only acts on short peaks (thunder, pops, strikes). Rain and fire loops are raised by up to 12 dB,
   so their noise floor is higher than in the source. MP3 56 kbps cap, mono, 32 kHz.

Total shipped audio: 22 loops, 4,688,224 bytes, about 4.7 MB (limit 6 MB).

Not used in round 3, with the reason:

- Cafe ambiance (CC0, 20 MB) and Restaurant ambience (PD): speech is likely and cannot be checked without listening.
- Ambient classroom mono (PD): same reason.
- Cicadas in Greece (PD), the Chinese cicada recording (CC0): the Greece file is clipped at 0 dBFS and both are a steady
  high drone, tiring over time.
- Edible frogs (PD, 24 s): the first 18 s are usable and the rest fades, too short for a clean loop.
- Country night noise (PD): the spectrogram shows a low rumble with one loud event, no crickets. Crickets are made in code instead.
- SingingBowl1 and SingingBowl2 (PD): 12.8 s and 9.3 s, below the 20 s minimum. The bowl is made in code instead.
- Waidachswald evening (CC0): level swings by 20 dB with loud bird peaks, not calm.
- Train passing in the Wirikuta Desert (CC0): a close passing train, not distant and not calm.
- Yellowstone sound library (NPS): US government work, not an author dedication, so outside the allow list.
- Snow steps, leaves rustle, library room tone: no file under an allowed licence was found.
- Internet Archive and OpenGameArt: not searched in this round. Commons gave enough files.

## Offline cache plan

- Precached at install: the 6 starter loops rain, stream, ocean, forest, birds, breeze (about 1.2 MB).
- Every other loop is cached on first play by a runtime rule in `web/vite.config.ts`: CacheFirst, same origin only,
  path `/samples/<id>.mp3.json` only, cache name `zonked-samples`, at most 40 entries. A loop heard once works offline.
- Made-in-code sounds ship no file and work offline from the first start.
- First load is unchanged: no sample is in the entry chunk.

## Proof of the public domain files

14 files rely on an author dedication to the public domain, not on CC0: rain, forest, birds, breeze, veranda, window,
waves, pebbles, chimes, gong, fire, creek, fountain and storm. For each one, the text of the Commons file page
(title, author, source record, and the dedication wording) was fetched on 2026-11-28 (UTC) and saved as
`docs/legal/samples/<id>.txt`. All 14 pages show a dedication by the named author:

- 12 pages come from PDSounds, where every uploader agrees to release recordings into the public domain. The Commons
  page also carries a fallback grant for countries where a dedication is not possible.
- 2 pages (waves and creek, both by Dsw4) are the uploader's own work with a self dedication and the same fallback
  grant.

What this proof does not show, and what we say plainly:

- Commons does not check that an uploader is the author. For the PDSounds files, the Commons page says the file was
  transferred from pdsounds.org. We rely on that statement. A saved page is evidence of what the page said on the
  date above. It is not a legal guarantee.
- The "Public domain" label here means a dedication by the author. It does not mean the Public Domain Mark.
- `node scripts/check-samples.mjs` only checks that every file is listed with an allowed licence name and that the
  hash matches this table. It does not check that the licence statement is true.
- Whether this proof is enough for a store listing is a question for a LAWYER.
- The CC0 rows (stream, ocean, rapids, lightrain, thunder, koshi, trickle, hum) link to the licence page. Their
  Commons file pages were read when the loops were made, but no saved copy exists yet. Saving them is listed in
  `docs/READINESS.md`.
- The storm page has unrelated spam text in its user tags. The dedication on that page is clear.

Nothing is marked for removal at this time. If a later check finds a page that no longer shows the dedication, the
file is removed (see below).

## Takedown

If you own a recording used here, or you believe a file is listed with the wrong licence, tell us:

1. Open an issue in the project repository titled "Sample takedown", and name the file (for example `rain.mp3.json`)
   and why. Do not post private data. If you prefer a private route, use the one in `SECURITY.md`.
2. We check the claim. If it looks right, we remove the file and its row, and list the removal here.
3. A removed file is removed in the next release. Builds already installed keep their cached copy until the app
   updates. Plan: loops will get content-hashed names so an update replaces them (wave E, see `docs/READINESS.md`).
4. We do not ask you to prove more than a normal claim needs. Tell us what you can.

This is a free project run by volunteers. It makes no promise about a fixed reply time, and a request is handled in
good faith.
